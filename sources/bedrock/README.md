# Bedrock (local textbook copies)

Full PDFs live here **on your machine only**. `*.pdf` (and other binaries) in this folder are gitignored, so
they never bloat the repo or a synced Claude Project's context.

What *is* committed: short Markdown chapter notes named `<source>__<chapter>.md`, e.g.
`ostep__ch42-crash-consistency.md`, `mixu__ch3-time-and-order.md`. DEEP_DIVE reads these first, then falls
back to the official free URL in `../MASTER_SOURCES.md`. Keep each under ~3,000 words: page references,
key definitions, and quotes you want to cite, not a re-typed chapter.

Recommended downloads (all free from the authors):
- OSTEP: concurrency + persistence parts (ostep.org)
- Tanenbaum & van Steen, *Distributed Systems* 4e (distributed-systems.net, free personal copy)
- Mixu, *Distributed Systems for Fun and Profit* (book.mixu.net/distsys)
- Google SRE Book + Workbook chapters (sre.google)
- Anthropic, *Building Effective Agents* (anthropic.com/research/building-effective-agents)
